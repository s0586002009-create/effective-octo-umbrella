# מסך מופרע – מהדורה 0.2

אפליקציית Android לתעלולים ויזואליים: יצורים מצוירים שמטיילים מעל אפליקציות אחרות, אפקט זכוכית סדוקה וכתמי לכלוך. כל הציורים נוצרים בזמן ריצה באמצעות Kotlin ו-Canvas; אין תמונות חיצוניות ואין הרשאת INTERNET.

## מה כלול במהדורה 0.2

- ממשק בעברית וב-RTL, עיצוב כהה, צבעי ליים/ורוד/תכלת וכרטיסים מעוגלים.
- 14 סוגי יצורים לבחירה, כולל בחירה של כמה מינים במקביל: זבוב, עכביש, מקק, נמלה, פרת משה רבנו, יתוש, דבורה, עקרב, לטאה, נחש, עכבר, שבלול, צפרדע ותולעת.
- עד 30 יצורים, מחוון גודל 16–200dp, מהירות משתנה וארבעה מסלולי תנועה: שיטוט חופשי, גלים אופקיים, קפיצות מהקצוות ותנועה אנכית.
- טיימר הפעלה של 0–180 דקות (0 = ללא הגבלה), עם עצירה אוטומטית בסיום.
- אפקטים נוספים: אדים, טביעות אצבע, כתמי קפה, דיו ופתיתי שלג, לצד סדקים ולכלוך.
- צליל קצר מסונתז מקומית בעת הפעלה, לפי בחירה; אין קובצי שמע חיצוניים.
- שכבת Canvas המתעדכנת דרך Choreographer, עם גוף מפולח, הצללה, כנפיים, עיניים, מחושים ופרטים שונים לפי סוג היצור.
- אפקט סדקים אקראי, אפקט כתמי לכלוך וניקוי מלא של כל שכבות האפקט.
- אפשרות מגע למעיכת יצור עם רטט; כברירת מחדל המגע עובר דרך האפקט.
- שירות Foreground עם התראה קבועה, כפתורי השהה/המשך ועצור, ואריח Quick Settings.
- עצירה בניעור, הפעלה לאחר אתחול (כבויה כברירת מחדל), ושלושה פרופילים מהירים.
- אשף פתיחה בן שלושה מסכים.
- תמיכה ב-minSdk 21, compileSdk ו-targetSdk 34.
- APK קטן ככל האפשר: אין נכסי תמונה/וידאו, אין פונט חיצוני, אין Compose ואין SDK של פרסומות או אנליטיקה. בניית Release מפעילה R8 ו-resource shrinking.

## מה עדיין אינו ממומש במלואו

המאגר הוא בסיס עובד להרחבה, ולא כל סעיף מהאפיון המקורי קיים בגרסה זו: אין כרגע סאונד מסונתז, בחירת כמה מינים במקביל, מסלולי תנועה נפרדים, טיימר הפעלה/עצירה, סנכרון DataStore, או מלוא קטלוג אפקטי הלכלוך/סדקים (למשל אדים, טביעות אצבע, קפה, דיו, שלג וסוגי שברים מתקדמים). נתוני ההעדפות נשמרים ב-SharedPreferences. מסך הפתיחה הוא הסבר קצר ולא אשף בן שלושה עמודים. ציורי היצורים הם איורי Canvas מפורטים, אך אינם תחליף למודלים תלת-ממדיים פוטוריאליסטיים. מצב "אפשר למעוך בלחיצה" משתמש בשכבת מגע מלאה ולכן במכשירים מסוימים עלול לתפוס לחיצות גם באזורים ריקים; במצב ברירת המחדל המגע עובר דרך האפקט.

## בנייה אוטומטית ב-GitHub

1. פתח את המאגר: https://github.com/s0586002009-create/effective-octo-umbrella
2. היכנס ללשונית **Actions**. אם GitHub מציג בקשה, לחץ **I understand my workflows, go ahead and enable them**.
3. בחר **Build Android APK** ולחץ **Run workflow** (או המתן לריצה שמופעלת אוטומטית אחרי push).
4. פתח את הריצה האחרונה. כשהסטטוס ירוק, גלול אל **Artifacts**.
5. הורד את screen-prank-debug.apk להתקנת בדיקה או את screen-prank-release.apk לשימוש רגיל. GitHub מוריד כל Artifact כקובץ ZIP; חלץ אותו, ובתוכו נמצא קובץ ה-APK.
6. בהתקנת APK ידנית, אשר לטלפון להתקין ממקור לא מוכר עבור היישום שממנו פתחת את הקובץ (למשל Files או מנהל הקבצים), ואז התקן.

## חתימה קבועה ל-Release

אם לא הוגדרו Secrets, ה-Workflow יוצר Keystore זמני כדי שה-APK יהיה חתום וניתן להתקנה. Keystore זמני שונה בכל ריצה, ולכן APK כזה לא יוכל לעדכן התקנה קודמת שנחתמה במפתח זמני אחר.

כדי שכל גרסאות ה-Release יהיו ניתנות לעדכון זו מעל זו:
1. צור Keystore קבוע במחשב מהימן באמצעות keytool: keytool -genkeypair -v -keystore screen-prank-release.jks -alias screenprank -keyalg RSA -keysize 2048 -validity 10000
2. שמור במקום בטוח את קובץ ה-JKS, סיסמת המאגר, alias וסיסמת המפתח. אל תעלה את קובץ ה-JKS ל-Git.
3. הפק מחרוזת Base64 לקובץ: Linux משתמש ב-base64 -w 0 screen-prank-release.jks; ב-macOS: base64 screen-prank-release.jks.
4. פתח GitHub → המאגר → **Settings → Secrets and variables → Actions → New repository secret**.
5. הוסף את ארבעת ה-Secrets בשמות המדויקים: KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS, KEY_PASSWORD.

ה-Workflow משתמש ב-Secrets אם כל ארבעת הערכים קיימים; אחרת הוא מייצר מפתח זמני לריצה.

## התקנה והרשאות בטלפון

1. התקן את קובץ ה-APK.
2. פתח את **מסך מופרע** ולחץ על **הפעל את הבלגן**.
3. במסך ההרשאה בחר באפליקציה והפעל **הצגה מעל אפליקציות אחרות** / **Display over other apps**.
4. חזור לאפליקציה. באנדרואיד 13 ומעלה אשר גם את הרשאת ההתראות כדי לראות את כפתורי העצירה בהתראה.
5. להפסקה, לחץ **עצור הכול** בהתראה או על כפתור ההפעלה במסך הראשי. אפשר גם להוסיף את אריח **מסך מופרע** לחלונית ההגדרות המהירות.

## פרטי פיתוח

- Kotlin, Gradle Kotlin DSL, AndroidX Core.
- Gradle 8.7, Android Gradle Plugin 8.6.1, Kotlin 2.0.21, JDK 17.
- אין הרשאת INTERNET, אין Analytics ואין פרסומות.
- GitHub Actions מייצר בזמן הבנייה את ה-Gradle Wrapper הרשמי (כולל gradle-wrapper.jar ו-gradlew), בונה assembleDebug ו-assembleRelease, ומעלה את שני קובצי ה-APK כ-Artifacts.
- דחיפת תג בשם v* יוצרת GitHub Release עם שני קובצי APK מצורפים.
